# Echoes of the Departed

A candlelit Victorian séance game where every voice is **Gemma 4**. Five
hand-written ghosts, each with their own scrying mirror, summonable, talkable,
resolvable. Some can pull you into the world they remember. The full design
is in [`SUBMISSION.md`](./SUBMISSION.md).

Submitted to the [Build with Gemma 4](https://dev.to/challenges/google-gemma-2026-05-06)
challenge.

## Install on macOS

1. **Download the latest release** from
   [github.com/iguana/echoes_of_the_departed/releases](https://github.com/iguana/echoes_of_the_departed/releases).
   Grab the `.dmg`.
2. **Open the `.dmg`** and drag `Echoes of the Departed.app` into your
   `Applications` folder.
3. **First launch — bypass macOS Gatekeeper.** I haven't paid Apple for a
   Developer Program code-signing certificate yet, so macOS will quarantine
   the app on first open. Use one of these workarounds:

   **Option A — right-click → Open (easiest):**
   In Finder, right-click `Echoes of the Departed.app`, choose **Open**, and
   confirm the security dialog. macOS remembers and won't ask again.

   **Option B — System Settings (after the first refusal):**
   When macOS says "cannot be opened", open **System Settings → Privacy &
   Security**, scroll to the bottom, click **Open Anyway** next to the app's
   name, then launch normally.

   **Option C — Terminal one-liner (most direct):**
   ```bash
   xattr -dr com.apple.quarantine "/Applications/Echoes of the Departed.app"
   ```
   This strips the quarantine flag and the app launches cleanly. Safe for
   apps you trust (you can read every line of source on this repo).

That's it for the app itself. The first launch shows an onboarding screen
that walks you through the one-time Ollama setup.

## Setting up Gemma 4

The game speaks to you through Gemma 4, served on your machine by
[Ollama](https://ollama.com). No API keys, no telemetry, no payments — just
a model you control. The onboarding screen offers three paths in order of
recommendation:

### 1. Ollama Cloud (recommended) — free, instant, zero disk

Best dialogue experience: full BF16 quality, ~550 ms first-token latency.

```bash
# 1. Install Ollama (one time)
brew install ollama   # or download from ollama.com

# 2. Sign in to Ollama Cloud (free account, opens a browser)
ollama signin

# 3. Pull the lightweight cloud-routed model (zero local disk)
ollama pull gemma4:31b-cloud
```

### 2. Local 4B (compact)

Runs entirely on your machine. ~3-5 GB on disk, 3-8 sec first-token on most
laptops, no GPU needed.

```bash
ollama pull gemma4:4b
```

### 3. Local 31B (best local quality)

Best local quality. ~19 GB on disk; **slow** on anything without a real
GPU (~10 sec first-token on Apple Silicon, painful on most x86 laptops).
Only worth it if you have the hardware.

```bash
ollama pull gemma4:31b
```

The game auto-detects whichever you've installed and prefers cloud > 31B >
4B for dialogue. If you mix-and-match (e.g., 4B local for level design,
cloud for streaming dialogue), the runtime auto-routes — your dialogue will
feel instant even if your local model is slow.

## How to play

You are the medium. Five spirit mirrors line the walls of an observatory
parlor; one altar stands at the south wall, locked.

| Key | Action |
|---|---|
| WASD / arrows | Walk the parlor (or the inside of a mirror world) |
| **E** | Commune with a mirror, or inspect an object inside a mirror world |
| **H** | Hear the medium's intuition — a single-sentence hint, in voice |
| Esc | Leave a séance, or step back through a mirror |

Each ghost wants something specific. Tell them, do them right by, and the
mirror will fade — they'll leave you a memento. Wrong them or mock them
and the mirror will shatter; they're gone. Help three find peace and the
central altar wakes.

Some ghosts will pull you *into* the world they remember. Walk it,
inspect what you find, and return changed.

## Build from source

If you'd rather build it yourself (the icon is generated by AI, the assets
are too — every pixel is in the repo):

```bash
git clone https://github.com/iguana/echoes_of_the_departed
cd echoes_of_the_departed

npm install
ollama serve &              # if not already running
npm run tauri:dev           # run in dev mode

# OR build a release .app + .dmg:
npm run tauri:build
# Output lands in src-tauri/target/release/bundle/{macos,dmg}/
```

### Adding music

Drop `.mp3` files into `soundtrack/` at the project root before building.
The game discovers them on next launch and plays them through the
in-game music widget (top-left of the parlor). Volume + mute are
persisted across sessions.

## What's in the box

- A Tauri 1.x desktop app (Rust + WebView)
- A Phaser 3 top-down parlor scene + mirror world scene
- 6 hand-written ghost characters in `src/ghosts/catalog.ts`
- Streaming Ollama client with structured tool-call support
- Painted artwork generated by `imagine` (Gemini Flash + GPT-Image-2),
  chroma-keyed for transparency where needed
- 54 Vitest tests
- Save/load via localStorage
- A debug bridge for headless testing (Vite middleware → frontend poll
  → `window.echo`)

Code is **MIT-licensed**. Artwork was generated by me through the
`imagine` CLI; treat it as MIT for redistribution alongside the game.

The `archive_v1_forge/` directory is the prior version — a level
generator I shipped, then archived after deciding the model was being
used the wrong way. It's there because the design story matters more than
the dead code.

## Performance footprint

Measured against `gemma4:31b` running on Apple Silicon via Ollama:

| Mode | Time-to-first-token | Total (~150 chars dialogue) |
|---|---:|---:|
| Local 31B with `think: true` | 6 minutes | 6.4 minutes |
| Local 31B `think: false` | ~10 s | ~42 s |
| Cloud 31B `think: false` | **~550 ms** | **~4 s** |

The game disables `think` mode by default and prefers `*-cloud` variants
for streaming dialogue automatically. See `SUBMISSION.md` for the
full design write-up.
